DOTFEED

Jedes Unicode-Braille-Zeichen kodiert ein Raster aus acht Punkten, zwei breit und vier hoch. DOTFEED nutzt dieses Raster als Bildschirm: ein Foto hinein, Punktgrafik heraus, die sich überall einfügen lässt, wo Text hinpasst. Alles passiert im Browser, kein Bild wird hochgeladen.

Technik
Eine HTML-Datei, Canvas API
Zwilling
Python-Kommandozeile mit Pillow, derselbe Algorithmus, gleiche Ausgabe
Stand
Veröffentlicht seit August 2026

Die echte Seite. Ein Bild hineinziehen, Dichte einstellen, Ergebnis kopieren.

Die Verarbeitungskette

Beschneiden. Das Bild wird auf sein Motiv zugeschnitten, damit leere Ränder keine Auflösung verschwenden.

Heruntersampeln. Jede Braille-Zelle deckt danach genau einen Ausschnitt des Bildes ab.

Schwellwert. Der Schwarz-Weiß-Trennpunkt wird je Bild automatisch bestimmt (Otsu-Verfahren) und lässt sich dann dichter oder lichter schieben.

Punkte setzen. In jeder Zelle gehen die Punkte an, die auf der dunklen Seite der Linie liegen.

Nie leer. Eine Zelle bleibt nie ganz frei: leere Zellen bekommen einen einzelnen stillen Punkt, damit Flächen texturiert bleiben, statt zu reißen.

Entscheidungen

Kein Server

Die Seite enthält kein fetch, kein XMLHttpRequest, keinen Beacon. Das einzige Externe sind zwei Schriften.

Ein Algorithmus, zwei Fassungen

Browser und Python-CLI liefern für dasselbe Bild dieselben Zeichen.

Auffindbar

Canonical, Open Graph, Sitemap und zwölf Topics im Repository, damit die Seite gefunden wird.
